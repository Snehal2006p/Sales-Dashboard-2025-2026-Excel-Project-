# Sales Dashboard 2025-2026 (Excel Project)

An interactive Sales Dashboard created in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and Data Visualization techniques.

## Features

* Total Sales, Profit, Quantity, and Target KPIs
* Region-wise Sales Analysis
* Department-wise Sales Distribution
* Month-wise Sales Trend
* Top 5 Product-wise Sales Analysis
* Interactive Slicers for Manager and Month filtering

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Dashboard Formatting

## Purpose

This project was created to practice data analysis and dashboard designing skills in Excel and to present sales insights in a visual and interactive format.
