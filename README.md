# Sales-Dashboard-2025-2026-Excel-Project-
Project Objective
Interactive Sales Dashboard built in Excel using Pivot Tables, Charts, and Slicers for data analysis and visualization. This project was created to practice data analysis and dashboard designing skills in Excel and to present sales insights in a visual and interactive format.
Features
Total Sales, Profit, Quantity, and Target KPIs
Region-wise Sales Analysis
Department-wise Sales Distribution
Month-wise Sales Trend
Top 5 Product-wise Sales Analysis
Interactive Slicers for Manager and Month filtering
Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Dashboard Formatting
